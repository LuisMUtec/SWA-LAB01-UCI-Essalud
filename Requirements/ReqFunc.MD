# Requerimientos Funcionales

Sistema de Gestión de UCI — Essalud

## Convenciones

- **ID:** `RF-<área>-<n>`
- **Prioridad:** MUST / SHOULD / COULD
- **Trazabilidad:** cada RF referencia la(s) persona(s) que lo motiva(n) y el problema crítico (P1/P2/P3).

| Área | Prefijo |
|---|---|
| Gestión de turnos | `RF-TUR` |
| Diagnósticos / handoff | `RF-DIA` |
| Notificaciones / escalamiento | `RF-NOT` |
| Pacientes | `RF-PAC` |
| Identidad y accesos | `RF-IAM` |
| Administración / reportes | `RF-ADM` |
